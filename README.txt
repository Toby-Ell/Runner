# Abdhul Rahmaan — Portfolio

## Files
- index.html
- style.css
- script.js
- assets/images/profile-placeholder.svg

## Add your own photo
1. Put your photo inside `assets/images/`.
2. Rename it to `profile.jpg` (or another filename).
3. In `index.html`, find:
   `src="assets/images/profile-placeholder.svg"`
4. Change it to:
   `src="assets/images/profile.jpg"`

## Run
Open `index.html` in a browser.
