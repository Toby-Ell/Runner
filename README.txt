ABD HUL RAHMAAN — GAMING STYLE PORTFOLIO
=========================================

FILES
- index.html: page content and structure
- style.css: futuristic gaming visual design
- script.js: navigation, filters, animations, form demo
- assets/images/profile-placeholder.svg: profile image placeholder

HOW TO OPEN
1. Extract this ZIP.
2. Keep all files/folders in the same structure.
3. Double-click index.html to open it in your browser.
4. Internet is needed for Google Fonts; the rest is local.

HOW TO ADD YOUR PHOTO
1. Copy your photo into assets/images/.
2. Example: my-photo.jpg
3. Open index.html in Notepad++.
4. Find assets/images/profile-placeholder.svg
5. Replace with assets/images/my-photo.jpg, then save and refresh.

BEFORE PUBLISHING
- Replace GitHub and LinkedIn placeholder links.
- Replace [YOUR EMAIL HERE] with your real email.
- Replace project GitHub/demo placeholder links.
- Add your CV file as cv.pdf in the project root, or edit/remove the Download CV link.

No fake work experience, certifications, achievements, companies, or statistics are included.
